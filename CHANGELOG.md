# Changelog

Versions follow semver. Code depends on token **names**, so:
- **Patch**: a value changes (a hex is adjusted).
- **Minor**: tokens or components are added.
- **Major**: a token is renamed or removed.

## 1.0.0 (10/04/2026)

First release. Palette D ("Blend") becomes the brand palette, replacing the warm cream system locked 09/02/2026.

- Two blues from the logo: logo blue `#25668F` for the band, navy `#173F5F` for headings and the dark panel.
- Burnt orange buttons `#C24A1E` kept; highlight `#E8692F` added; text links move to `#B5441B` (button orange is 4.44:1 on the ground, under 4.5).
- Cool gray ground `#F2F4F6` with white surfaces replaces cream `#FFFDF9`.
- Supporting colors chosen 10/04/2026: muted `#44566A`, meta `#56687A`, dividers `#D9E0E7`, input borders `#808C99`.
- Pillar tints and headings updated to the D values. Pillar body text is now ink on every tint.
- Band body text and the learning tint merged into one value, `#E1EDF5` (they differed by one step).
- Type moves to Bricolage Grotesque (display) and Figtree (body). Both OFL, self-hosted in `fonts/`.
- New: `color.status.danger` `#B42318`, not yet used anywhere.
- Print mode: white ground, 4-6px radii, no shadows.
