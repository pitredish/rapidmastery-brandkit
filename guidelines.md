# Rapid Mastery visual guidelines

For people. Agents should read `AGENTS.md`, which has the same rules in checklist form.

## Color roles

| Role | Token | Hex | Use |
|---|---|---|---|
| Ground | `color.bg.ground` | `#F2F4F6` | Page background |
| Surface | `color.bg.surface` | `#FFFFFF` | Cards, modules, lists |
| Brand band | `color.bg.brand` | `#25668F` | The blue band, learning pillar |
| Navy | `color.bg.brand-deep` / `color.text.heading` | `#173F5F` | Dark panel, headings |
| Ink | `color.text.primary` | `#1B232B` | Body text |
| Muted | `color.text.muted` | `#44566A` | Secondary text |
| Meta | `color.text.meta` | `#56687A` | Eyebrows, captions, dates |
| Button | `color.action.primary.bg` | `#C24A1E` | Primary buttons |
| Button hover | `color.action.primary.bg-hover` | `#9C3A16` | Hover only |
| Link | `color.text.link` | `#B5441B` | Inline links, underlined |
| Highlight | `color.highlight.bg` | `#E8692F` | Progress, due pills. Dark text |
| Peach | `color.on-brand.emphasis` | `#FFB98F` | One word on the band |
| Line | `color.border.default` | `#D9E0E7` | Dividers, card hairlines |
| Input | `color.border.input` | `#808C99` | Form field outlines |

## Layout

Content max 1000px. Side gutter 40px, 28px under 900px, 18px under 480px. 80px between major sections on marketing pages; 24-32px in tools. Three-column grids collapse to one under 760px.
